# Verificador de Domínios com Python e Rich

Lê uma lista de domínios de `dominios.txt` e exibe em tabela o **IP** resolvido e o **código de status HTTP** de cada um, continuando a execução mesmo em caso de erro.

## Pré-requisitos

- Python 3.10+
- Dependências: `rich` e `requests`

## Instalação

```bash
pip install rich requests
